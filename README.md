# Insect Catch Game 🐞

## 📌 Project Overview

Insect Catch Game is a fun and interactive browser-based game where players catch insects by clicking on them. As the game progresses, the gameplay becomes more challenging, making it an engaging experience.

This project was developed to practice JavaScript DOM manipulation, event handling, and dynamic web interactions.

## ✨ Features

- Interactive insect-catching gameplay
- Click-based player interaction
- Dynamic game progression
- Multiple insect selection
- Simple and engaging user interface
- Responsive design

## 🛠️ Technologies Used

- **HTML5** – Provides the game structure.
- **CSS3** – Handles styling, layout, and animations.
- **JavaScript** – Controls game logic, interactions, and dynamic elements.

## 📚 Key Concepts Practiced

- DOM Manipulation
- Event Listeners
- JavaScript Functions
- Dynamic Element Creation
- CSS Animations
- Game Logic and Event Handling

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Start playing and catch the insects!
